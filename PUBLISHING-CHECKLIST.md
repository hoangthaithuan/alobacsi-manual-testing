# Publishing checklist — ALOBACSI

Before switching the repository to **Public**:

- [ ] Confirm the training/application materials are permitted to be shared publicly.
- [ ] Inspect every worksheet for real phone numbers, passwords, OTP values, names, email addresses, patient information, and other private information; redact if needed.
- [ ] Check any links, images, comments, hidden sheets or embedded objects for private or restricted information.
- [ ] Verify the displayed project name and screenshots are authorized for portfolio use.
- [ ] Check that workbook files and the README display correctly on GitHub.
- [ ] Preserve historical statuses and incomplete results transparently; do not convert unexecuted cases into Passed.
- [ ] Do not include private employer or client materials.

**Note:** The original workbook is included unchanged in this starter package. It has not been certified as sanitized. Create the GitHub repo as Private first.
