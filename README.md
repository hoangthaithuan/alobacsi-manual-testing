# ALOBACSI — Manual Testing Practice Portfolio

**Project type:** QA practice / learning project  
**My role:** Manual QA learner — test case design and execution practice  
**Application:** ALOBACSI, a healthcare appointment-booking application  
**Artifact:** [Test case workbook](test-cases/ALOBACSI-Test-Cases-and-Plan.xlsx)

## Overview

This repository documents my manual software testing practice for the ALOBACSI application. I created and recorded test cases across account management, doctor discovery, appointment booking and related user flows. The Excel workbook preserves the original training work and its recorded observations.

This is **learning-project documentation**, not a claim of employment with ALOBACSI, a production QA engagement, or an independently verified current test run.

## Coverage

The workbook contains **85 test cases with IDs across 13 feature worksheets**, excluding the template worksheet. Counts reflect identifiable test case rows in the supplied workbook, not a claim that all cases were executed or passed.

## What the workbook demonstrates

- Defining preconditions, test steps and expected outcomes for user-facing functionality.
- Exploring positive and negative scenarios across account and appointment workflows.
- Recording observed behaviors and execution statuses where available.
- Organizing coverage by feature and user journey.

> **Execution caveat:** Some worksheets include recorded results, while some entries are incomplete. The workbook is shared as an original practice artifact, and its historical statuses should not be interpreted as a freshly reproduced test run. See the workbook for each case's actual details.
